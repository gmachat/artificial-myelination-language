# AML to JavaScript demonstration

This project shows an AI-friendly AML program compiling into ordinary,
dependency-free JavaScript. The example uses records, typed lists, optional
values, task contracts, conditions, task calls, and the conventional `main`
entrypoint.

## Project layout

```text
main.aml       source an AI or person writes
build/app.js   JavaScript generated by AML
test.mjs       dependency-free behavior test
```

## Run with standalone AML

From this directory:

```sh
AML="../../release/aml-0.8.0.dev0-macos-arm64/aml"

"$AML" check main.aml --target javascript
"$AML" run main.aml --target javascript
```

## Rebuild the JavaScript

```sh
mkdir -p build
"$AML" build main.aml --target javascript -o build/app.js
```

The generated JavaScript contains AML's deterministic runtime validation and
contract checks. No npm install is needed for this core JavaScript project.

## Run and test the generated file

```sh
npm run demo
npm test
```

You can also run it directly:

```sh
node build/app.js
```
